# Verification boundaries

The accepted pre-export baseline (2026-11-01) reported core 2,829 tests: 2,825 passed and 4 skipped; social 480 tests: 476 passed and 4 skipped. These are full integration-baseline counts, not independent public-repository test results.

The same accepted baseline includes a real Electron application running three synthetic reading scenes, and actual formal installation with both plugins loaded. Synthetic material and stubbed provider responses do not establish live Bilibili or QQ behavior. Older changelog statements about an unconnected bridge or unexecuted final installation describe their historical revision, not the accepted current baseline.

Live Bilibili account playback/subtitle/frame reading through a real paid model, commenting, QQ login and a real QQ inbound -> model -> outbound roundtrip, real media semantics, multi-screen behavior and external platform delivery/read status have not been accepted by that evidence. Do not claim that successful receipts establish perfect understanding, or that a synthetic test establishes successful external delivery. Public-download/clean-profile-install verification and exported-suite counts require separate release receipts.

This source/package patch keeps the accepted Bilibili 2.0.10 / QQ 2.0.5 functional code, apart from patch version identifiers. It introduces packaging, documentation and independent build/test boundaries. No new live platform, model, signing, publication or installation result is asserted by this document. The root coordinator owns those gates.
